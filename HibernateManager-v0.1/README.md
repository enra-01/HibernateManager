# Hibernate Manager

MVP Android application for Android 8-12 and Shizuku.

## Build

GitHub Actions automatically builds a debug APK on every push to `main`.

## Current MVP

- RAM information
- Installed user-app list
- Shizuku status
- Shizuku permission request
- GitHub Actions APK build

Hibernate execution is intentionally not enabled yet. The next implementation step is to add the Shizuku-backed stop/hibernate operation and per-app selection.
